## 👋 Hi, I'm Sayidi

I'm a student from Bangladesh. While the biggest companies in the world race to build AI agents, I kept asking myself one question:

> **Can one person, with one laptop and no team, build a real AI agent engine?**

I tried. The answer is **ZYRAXON AI**: an open-source desktop agent that doesn't just answer.
**It does the work.**

<br/>

## ⚡ What ZYRAXON does

A chatbot gives you words. ZYRAXON takes a **goal** and carries it all the way to a **result**.

```mermaid
flowchart LR
    A([🎯 Your goal]) --> B[🧭 Plan]
    B --> C[🧰 Pick tools]
    C --> D[⚙️ Execute]
    D --> E[👁️ Observe]
    E --> F{✅ Done?}
    F -- not yet --> B
    F -- yes --> G([🏁 Result])
```

It plans the steps, picks the right tools, runs them, reads what came back, fixes its own mistakes, and **checks the job is actually finished** before it tells you it is.

## 🔌 XXXX MCP servers, ready to connect

MCP servers are the agent's **hands**. More hands, more power. ZYRAXON's MCP Hub brings **XXXX MCP servers** together from the official MCP registry and other public directories, so your agent can reach the tools you already use.

Every server connects the way it needs to, and ZYRAXON shows you only the step that matters:

| If the server needs… | What you'll see |
|---|---|
| 🌐 **A browser sign-in** | ZYRAXON opens the login page, you approve, you're connected |
| 🔑 **An API key** | A short form asks for the key and keeps it masked |
| 🔗 **Your own URL** | You paste your instance address and go |
| ⚡ **Nothing at all** | One click, connected |
