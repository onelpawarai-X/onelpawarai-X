# 🌌 About ZYRAXON

ZYRAXON AI is an **open-source AI ecosystem** focused on building intelligent desktop software, mobile assistants, and developer tools that combine automation, voice interaction, vision capabilities, and modern interfaces.

The ecosystem currently includes:

- 🖥️ **ZYRAXON AI** — Desktop AI Agent
- 📱 **Myra Agent** — Android Voice Assistant
- 💻 **Zyraxon Code** — AI-powered Code Editor
